# Contributing

## Setup

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
```

Python 3.10+. Runtime dependencies are numpy, pandas, scipy, scikit-learn and
matplotlib. Tests use the standard library `unittest` only, so a clone with no test
framework installed still runs the suite.

## Ground rules

- All data is generated by `scmplatform.datagen`. Do not add a dataset to the repository.
- Every number in `README.md` comes from `benchmarks/run_benchmarks.py`. If a change
  moves a number, re-run the benchmarks and update both the README and
  `benchmarks/results.md` in the same commit.
- New feature transforms must be covered by the point-in-time audit. If a transform
  cannot pass `truncation_check`, it does not belong in `default_specs()`.
- Behavioural changes need a test. Bug fixes need a test that fails before the fix.
- Decisions with consequences go in `docs/adr/` in context/decision/consequences form,
  numbered sequentially.

## Before opening a pull request

```bash
make test
make bench
make example
```
